# Transitions

Elite empirical-economics prose generally prefers semantic continuity over decorative transition language.

## Preferred transition families

### Contrast
- but
- while
- whereas
- however
- in contrast

### Narrowing
- more specifically
- in particular
- among...
- within...

### Consequence
- therefore
- thus
- as a result
- this implies... (only when implication is valid)

### Addition
Often no marker is needed. If needed:
- also
- in addition

### Return to design/evidence
- to test this...
- to distinguish these explanations...
- we next examine...
- we then estimate...

## Avoid
- furthermore/additionally/moreover in repeated sequence;
- "against this backdrop";
- "from a broader perspective";
- "it is worth noting";
- transitions whose only purpose is to signal paragraph order.

## Transition test
Delete the connector. If the relation remains obvious, prefer the version without the connector.
